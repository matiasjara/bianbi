# Marca Bianbi

## Assets
- `logo.png` — wordmark real (versión para fondos oscuros)
- `logo-dark.png` — mismo wordmark en carbón (fondos crema)
- `logo-white.png` — wordmark blanco
- `iso.png` / `iso-light.png` — isotipo pin+ruta (también favicon)
- `icons/` — documentación de iconos UI (Phosphor vía código)
- `manual/` — páginas del manual de marca

## Tokens (código)
Ver `src/lib/brand/tokens.ts` y variables CSS en `src/app/globals.css`.

### Tipografía
- Principal (geométrica): Syne / Manrope — logo, nav, datos
- Secundaria (editorial): Fraunces — titulares y relatos

### Logo
- Ancho mínimo digital: 120px
- No rotar, no distorsionar
- Fondo limpio (crema o carbón); no sobre fotos ocupadas
